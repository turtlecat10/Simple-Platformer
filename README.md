# Simple-Platformer
For terra hackclub

controls: arrow keys for movement (down on magenta platforms to go through them) Z for zooming
X for dashing (please don't press modifier keys (shift, ctrl, alt, etc..) it bugs slightly)
red kills you

To download, go to releases, select latest release, download the .zip (or .exe) and extract it
from there run the .exe and have fun!

This is a simple platformer I plan to update later with new things including hopefully enemies
when you enter you should see a blank screen with grid lines, go to the right side and you will
see a panel, this is for making custom maps. Map 1 is already made (not finished)
left click to place the bottom left and right click to place the top right (it doesn't actually matter
which order you click with, however if you don't have the bottom left be left click it places wierdly
and i need to fix that but not yet). Middle click to select an object to be able to delete it, and 
press play when you are ready, when you exit out of the tab or load another game it deletes what you
modified if you didn't save. load back other maps by typing in the map id for them and pressing load

if you enjoyed playing please message me with what features you think i should add! (feedback is appreciated)
also if you go into the src folder and look at levels.json you can copy/paste to let other people play your level
